# 英検4級 スペースアカデミー

英検4級の合格をめざす、iPad 向けの学習 PWA です。宇宙がテーマで、うさぎの宇宙飛行士「ルナ先生」といっしょに「合格星」をめざします。
ビルド不要の素の HTML / CSS / JavaScript（ES Modules）で作っています（英検3級パスポートと同じ構成）。

## 4級に合わせたポイント

| 本番の形式 | このアプリでの対策 |
|---|---|
| 筆記 大問1 語句の空所補充（15問） | 177問（名詞・動詞・形容詞・副詞・熟語・文法14項目）＋AIで問題を追加・過去問の取り込み |
| 筆記 大問2 会話文（5問） | 53問。答え方とセットの会話表現75（単語帳）と文法レッスン「依頼・提案・さそい」 |
| 筆記 大問3 **並べかえ**（5問）※4級だけの形式 | 63問。**タイルを並べるパズル**（タップ・ドラッグ）→ **本番形式**（2番目と4番目の組合せを選ぶ）→ **英文をまるごと書く**（手書き・キーボード）の3段階 |
| 筆記 大問4 長文（掲示2・Eメール3・説明文5） | 15題50問。Eメールは差出人・件名つきで表示、単語タップで発音 |
| リスニング 第1部（イラストつき・3択・選択肢は音声のみ） | 30問。場面のイラスト（絵文字で構成）を見ながら聞く |
| リスニング 第2部・第3部 | 各30問。本番どおり2回放送、答え合わせでスクリプトを1文ずつ再生 |
| スピーキングテスト（コンピューターで受ける録音式・別判定） | 本番と同じ流れ（黙読20秒→音読→No.1〜No.4）。No.4 は Yes/No で分かれる質問。解答時間のバーつき。問題カード10枚（SVGのイラスト） |
| 4級は過去形の文がとても多い | **過去形マスター**：不規則動詞＋つづりに注意する規則動詞79語。goed・wented などまちがえやすい形から選ぶ4択と、手書き |

## 主な機能

| 機能 | 内容 |
|---|---|
| 手書きスペル判定 | Apple Pencil・指でつづりを書くと自動で採点。**1マス1文字**で認識するので単語の自動補正が入らず、まちがえた文字が赤く出る。4線ノートのマス・1行書き・キーボードから選べる |
| 忘却曲線による出題 | 単語・問題ごとに「記憶の安定度」を記録し、定着度が90%を下回るころに再出題（FSRS 風）。まちがえたものは同じ回の少しあとにもう一度、以降も早め・多めに出題 |
| スマート単語帳 | 単語658・熟語135・会話表現75（重要度 A/B/C・**テーマ別15分類**・例文と訳・不規則変化）。フラッシュカード／**高速周回**（スワイプで1枚1秒・周回タイム記録）／4択／聞いて選ぶ／手書きスペル／ディクテーション |
| メテオバスター | 60秒の単語バトル。落ちてくる隕石の単語の意味を選ぶとレーザーで撃ち落とす。5連続で+3秒、まちがえると−3秒。結果は忘却曲線にも反映 |
| 文法レッスン | 4級の14項目（過去形・過去進行形・未来・助動詞・依頼表現・不定詞・動名詞・比較・There is・接続詞・疑問詞・代名詞・前置詞・文の形）。例文の読み上げ、その文法の4択・並べかえへ |
| AI 解説 | 解説のあとに「AI先生にくわしく聞く」「AI先生に質問」。並べかえは語順の考え方を解説、英文を書く問題は「この書き方でも正しい？」を判定。回答は端末に保存して再利用（2回目からは無料） |
| AI スピーキング | 試験官（ルナ先生）が読み上げ、音声認識で答える。音読の一致率とキーワードで無料採点、AI で内容まで見た採点も可 |
| 模擬試験 | 本番サイズ（筆記35問35分 → リスニング30問）・筆記だけ・リスニングだけ・ミニ模試。**マークシート風の解答用紙**、中断・再開、CSE スコアの目安、大問別の成績、見直し |
| 合格予測 | 直近の正答率から技能別の CSE スコアを換算し、合格ライン（一次622／スピーキング324）と比べて表示。ホームの「合格星」までのロケットの位置でも見える |
| 記録 | 学習カレンダー（12週）・14日のグラフ・忘却曲線の予測・復習の予定・大問別の正答率・苦手ランキング・**おうちの人向けの1週間のまとめ** |
| やる気の仕組み | XP・レベル・階級（訓練生→銀河マスター）、コンボ、ミッションワッペン28種、今日のミッション、試験日までのカウントダウン、流れ星・紙吹雪・爆発などの演出、効果音（Web Audio で合成・音声ファイルなし） |

## 使い方（iPad）

1. HTTPS で配信されている URL を Safari で開く（下の「公開のしかた」を参照）
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、全画面・オフラインで使えます

- 設定 →「プロフィール」で試験日を入れると、ホームに「打ち上げまであと○日」が出ます
- スピーキングの音声認識を使うには、iPad の「設定 → 一般 → キーボード → 音声入力」をオンにし、マイクを許可してください（使えないときは文字入力で答えられます）
- 読み上げの声は「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語」で高音質の声（拡張・プレミアム）を追加すると自然になります
- Pixel / Android の Chrome でも動きます（Google の音声で読み上げ・認識）

> 学習記録は端末のブラウザ内（localStorage / IndexedDB）に保存されます。Safari の「履歴と Web サイトデータを消去」で消えるため、
> 設定画面の「バックアップを保存」でときどき書き出してください（API キーはバックアップに含まれません）。

## AI の設定

### アプリ内蔵AI（利用者の設定は不要）

英検3級アプリと同じく **Modellix の無料 LLM（`modellix-ai/free-llm`）** を、Cloudflare Worker の中継経由で使います。
中継は3級アプリ用に公開済みの `eiken3-ai` を共用しています（`js/config.js`）。

- 4級アプリも `https://sleipnir167.github.io/…` で公開すれば、中継が受け付けるサイト（オリジン）は3級と同じなので**追加の設定は不要**です
- 手元（`http://localhost:8767`）で AI を試すときは、中継の `ALLOWED_ORIGINS` に `http://localhost:8767` を追加してください（くわしくは [proxy/README.md](proxy/README.md)）
- 4級専用の中継にしたい場合も [proxy/](proxy/) から公開できます

### クレジットを節約するしくみ

- **AI なしでも全部動く**：全問に日本語の解説・訳つき。手書き判定・スピーキングの採点・英文チェックは端末内で動き、AI はボタンを押したときだけ使います
- **回答の保存**：同じ問題・同じまちがいへの解説は IndexedDB に保存し、2回目からは AI を呼びません
- **出力を短く**：採点は JSON で返させ、小さなモデル（自前の Gemma など）でも安定するようにしています

### 自分の AI を追加する（任意）

設定 →「AI」で、内蔵AIの下に OpenAI 互換の接続先を追加できます（上から順に試し、失敗したら次へ）。

| 接続先 | URL の例 | モデルの例 |
|---|---|---|
| 自前サーバー（Oracle Cloud の Gemma など） | `https://your-server/v1` | `gemma3:12b` |
| OpenRouter | `https://openrouter.ai/api/v1` | 「モデル一覧」で料金つきの一覧を取得（安い順） |

自前サーバーを使うときは、HTTPS 化と CORS の許可（Ollama なら `OLLAMA_ORIGINS`）が必要です。
自分で登録した API キーはその端末の中だけに保存され、バックアップファイルには含まれません。

## 手書き判定のしくみ

`js/recognizer.js` / `js/spell.js` / `js/screens/order.js`

1. **オンライン**：Google 手書き入力 API に**1マスずつ別々に**線の座標を送り、返ってきた候補の上位に正解の文字があるかで判定（`l` と `1`、`o` と `0` などの取り違えは同じ文字とみなす）
2. **オフライン**：アルファベットのお手本（`js/letters.js`）と $P 点群認識で照合し、4線のどこに書いたか（上に出る・下に出る）と i / j の点も手がかりにする簡易認識
3. **英文を書く問題**：2行のノートに書いた線を行ごとに分けて認識し、正解の英文と比べる（I'm と I am などは同じとみなす）。ちがうときは赤い語で差を表示
4. **自分で判定**：お手本と見比べて ○／× をつける

認識ミスのときは答え合わせで「読み取りミス（正しく書けていた）」を押すと記録を直せます。
「自動」では書いた線の座標データが Google に送信されます。送信したくない場合は設定で「端末内のみ」を選んでください。

## 開発

```bash
npm start
```

`http://localhost:8767` で確認できます（Service Worker は localhost か HTTPS でのみ動きます）。

```bash
npm run check
```

問題データを検証します（選択肢の数・重複・空所・例文の { }・並べかえの語数・長文の設問数など）。

### 問題を追加・修正する

- 単語・熟語・会話表現：`data/words.js`（1行＝`単語|品詞|意味|例文（{ }が見出し語）|訳|重要度|変化形|テーマ`）
- 過去形：`data/verbs.js`（`原形|過去形|意味|例文（{ }が過去形）|訳|i または r`）
- 大問1・2：`data/reading.js`（1行1問・選択肢は正解を先頭に書く。出題時にシャッフル）
- 大問3：`data/order.js`（`日本文|( )の前|語句を正しい順に5つ|( )のあと|文法キー|解説`。2番目と4番目に同じ語を置かない）
- 長文・リスニング・スピーキング：それぞれ `data/` の各ファイル

問題の ID は問題文から作るハッシュなので、問題文を変えるとその問題の学習記録はリセットされます。
追加・修正したら `npm run check` で検証してください。

### 公開のしかた

静的ファイルだけなので、GitHub Pages・Netlify・Cloudflare Pages などにフォルダごと置けば動きます（HTTPS が必要）。
ファイルを更新したら `sw.js` の `VERSION` を上げると、アプリ内に「新しいバージョンがあります」と表示されます。

## 注意

- 問題・例文はすべて本番の出題形式にならったオリジナルです。過去問の転載ではありません
- 英検の過去問（直近3回分）は日本英語検定協会の公式サイトで公開されています。「筆記 → 問題をふやす → 取り込む」で自分の学習用に大問1形式の問題を追加できます
- CSE スコア・スピーキングの点数はアプリ独自の換算による目安です（実際の CSE は統計的に算出されます）
- 本アプリは公益財団法人 日本英語検定協会とは関係ありません
